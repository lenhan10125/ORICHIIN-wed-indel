Inkscape là gì?

Inkscape là phần mềm mã nguồn mở dùng để thiết kế đồ hoạ vector, hoàn toàn miễn phí và đa nền tảng (Windows, macOS, Linux). Phần mềm phù hợp cho nhà thiết kế đồ hoạ, giáo viên, học sinh và bất kỳ ai cần tạo hoặc chỉnh sửa hình ảnh vector chất lượng cao.

Khác với đồ hoạ raster (JPEG, PNG), hình ảnh vector trong Inkscape được mô tả bằng toán học, nên sẽ không bao giờ bị vỡ hình dù phóng to đến bất kỳ kích thước nào — lý tưởng cho in ấn và trình chiếu.

Vì là phần mềm mã nguồn mở, người dùng có thể tự do sao chép, chỉnh sửa và phân phối lại theo giấy phép GPL.

Cách tải và sử dụng file của chúng tôi

1
Nhấn nút "Tải ZIP" trên thẻ file muốn dùng

File sẽ được tải về máy tính dưới dạng .zip. Kiểm tra thư mục Download nếu không thấy cửa sổ lưu file xuất hiện.

2
Tìm file .zip vừa tải trong thư mục Download

File thường có tên dạng caynam-basic.zip hoặc filetinhoc10.zip. Chưa mở được ngay — bạn cần giải nén trước.

3
Giải nén file ZIP

Nhấp chuột phải vào file .zip → chọn "Extract Here" hoặc "Extract to [Tên thư mục]". Bạn có thể dùng công cụ tích hợp sẵn của Windows/macOS, hoặc cài thêm 7-Zip / WinRAR (miễn phí).

4
Mở thư mục sau khi giải nén

Bên trong bạn sẽ thấy các file có đuôi .svg hoặc .png. File .svg là file vector dùng để chỉnh sửa trong Inkscape.

5
Mở file bằng Inkscape

Nhấp chuột phải vào file .svg → chọn "Open with" → chọn Inkscape. Nếu Inkscape chưa được cài, tải tại inkscape.org (miễn phí hoàn toàn).

6
Chỉnh sửa hoặc xuất file

File sẽ mở trong Inkscape với đầy đủ các layer, màu sắc và hình dạng. Bạn có thể chỉnh sửa tự do: thay màu, thêm chữ, resize... Sau đó xuất ra PNG hoặc in trực tiếp.
